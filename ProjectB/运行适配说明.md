# 相对原审计包的运行适配

`reference/` 逐文件保留原包，原 SHA256SUMS 和模型/阈值冻结收据不改。完整外层包有新的 manifest 和整体 SHA-256。

`src/` 为可运行代码副本。唯一修改的既有计算入口是 full_data.py：当 PROJECTB_PREPARED_DIR 存在时，只从包内两份数据数组读入，仍按历史 prepared.json 的 SHA 核验相同字节，不回退读取旧盘符。图/标签/特征/模型/损失/池化/阈值计算源码保持原样；full_data.diff 给出精确差异。

新增 run.py、portable_tasks.py、sitecustomize.py 和 CMD 启动器。数据重建调用原 v5_graph、v5_prepare.grid、full_prepare.construct/stats；只把 source_files 的输入指向包内同哈希 CSV。新训练初始化从 reference 复制已哈希的静态对照，注册包内快照与相对路径绑定，再调用原动态训练/选择/冻结/评价流程。默认不重新训练静态对照，因此 18 次新动态训练、18 次静态模型复用分别计数。

所有命令显式使用调用它的 niulaoshi Python。没有安装包、修改 Conda 或写入全局 site-packages；sitecustomize 仅通过本次子进程的 PYTHONPATH 生效，用于拒绝旧任务文件路径访问。任意盘符/含空格解压位置可用。数据和模型安全加载分别为 allow_pickle=False 与 weights_only=True。

参考指标复算、重放和重新训练是三个不同命令。重新训练的本地验收范围详见 本地运行验证.json；未完成完整训练时不会以 smoke 证明完整训练成功。
