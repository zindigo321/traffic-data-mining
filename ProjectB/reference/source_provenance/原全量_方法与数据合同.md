# 全量数据实验方法与数据合同

全部数据指纽约项目既定121有向路段、07–09和17–19双高峰范围内，已取得并通过哈希与模式校验的全部源记录。52份历史分片与2份续期分片在source_snapshot逐条登记。原始速度单位mph，日期以America/New_York民用时间构造十分钟格。原始分片按原速度>0且≤85、旅行时间>0、固定路网规则筛选，状态字段不单独丢弃有效速度。原始行及筛选漏斗保留，所有固定格都生成预测，未知标签留作覆盖。 [官方NYC DOT数据](https://data.cityofnewyork.us/d/i4gi-tjb9)

标签继续用原双格规则。每格需合格的两个五分钟半格；按同道路、时段、日类型，至少三个合格过去日构建历史均速。相邻两格分别低于可用历史均速40%确认正类，观测不足、历史不足或未连续确认低速为unknown。新协议取消实验入口的等待和覆盖条件，不改变原真值计算。首次高峰格因缺少连续历史速度可能无合法lag20，仍出分，缺失组单列。

开发训练[05-11,08-03)，开发验证[08-03,08-31)。最终训练[05-11,08-31)，校准[08-31,09-28)，回溯测试[09-28,11-12)。最终训练112天171672已知窗、4649正例、167023负例；校准28天47780已知窗；测试45天80536已知窗。所有日期都在训练或后续评价范围。扩展训练时历史均值按当时已有过去观测逐日更新，校准/测试统一冻结训练历史。旧已公开留出参与本次回溯，测试日期公开性记录在报告。

目标格t在起点前10分钟出分，最新动态输入来自[t−20,t−10)及更早，标签涉及的[t−10,t)和[t,t+10)速度只在真值侧。52列合法特征由原V7forecast_inputs生成，中心及相邻路段同样截断。历史转移统计也只在训练日更新，校准和测试期间冻结。源表无独立到达时间，以data_as_of作为离线可用时点。

Graph Transformer复用有向结构掩码多头注意力。节点为有向路段，图56条候选方向边由既定几何端点和转角约束构造，孤立节点54个。目标中心为局部节点0，一跳子图最多5个有效节点，padding有独立mask。输入为[B,N,104]，由52列训练集填补/缩放值与缺失位组成。隐藏维32，2层、4头，注意力logit为[B,4,N,N]。允许目标关注物理前驱和自身，禁止跨图、跨batch注意力。每层主注意力复杂度O(BN²D)，本固定图N≤5。空图拒绝，单节点图可正常执行。

池化向量与目标节点向量拼接后，64维分类器给该路段十分钟格一个logit。Mean为sum(valid_i h_i)/sum(valid_i)，Max为有效节点逐维最大，Attention为softmax(wᵀh_i+b)加权求和。三者池化均O(ND)，Attention额外33参数。三种池化独立训练和评价。核心源码为project/v10/v9/v8/v7/v6/v5/v4/v3/v2/v1/model.py。

五个全量配方在每轮每条已知训练样本恰访问一次。步数匹配抽样中心对照固定12000负例及全部正例，将同一随机排列循环到全量样本访问数；因此全部六配方每轮步数一致，抽样控制的唯一ID数和重复数明确记录。训练12轮、batch128、学习率0.001、种子11/22/33、每任务CPU2线程。中心排序组增加V10原合法低速组内softplus负正logit差，取该组最高分四分之一负例，权重0.35。逻辑回归使用相同合法中心特征、训练集标准化和全部已知训练样本。

checkpoint只由开发AP选择，最终训练保存轮次是每配方三个开发种子的中位数，实际仍执行12轮。三池化主模型由开发三种子平均AP选择，AP并列按约束F1和登记顺序。最终模型与阈值冻结后才计算测试指标。最终神经模型均与确定性基线在完全一致的测试键上比较。

主要工作点为校准段受约束最大F1，预算按完整日历天计总FP≤12/日、恢复FP≤6/日；另报校准最大F1阈值的取舍。误报是路段窗口计数，事件按同道路连续十分钟正例合并。AP使用average_precision_score，另报ROC-AUC、BA、正类F1和混淆。类别不足时相应指标N/A。等召回50/60/70/80%按相同TP、分数降序、键打破并列，主点60%，全支持和合法低速组分别计算。1000次共享日历日分块给配对区间。

原始分片与特征数组外部只读存放，包内给出哈希和重建入口。NPZ只用allow_pickle=False，权重只用weights_only=True。合成样本只作工程测试，真实模型和结果另列。纽约估速、路段覆盖、几何推断和来源时点均有偏差，原Geolife课程和Chicago原口径结果分开记录。
