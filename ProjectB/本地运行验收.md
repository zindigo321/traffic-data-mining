# niulaoshi 本地运行验收

在含空格的新目录，以 niulaoshi 的真实 Python 执行了 CMD/Conda 启动、原始数据重建、指标复算、36 模型重放、三池化小批训练、测试和完整重新训练。没有修改 Conda 环境。

完整训练实际执行了 18 次动态模型 fit，每次 12 轮，静态对照另计为 18 次已核验复用。全部新权重 SHA 与原参考实验一致，全部汇总指标逐值一致；不是以 smoke 替代完整训练。

81 项测试（75 模型工程 + 6 便携适配）通过；两份 prepared 数组从包内原始数据重建后 SHA 相同；36 个模型重放最大概率差为 0；导出 130,680 个测试窗口，含 50,144 个 unknown。

详细命令、解释器、退出码、用时和控制台日志见 本地运行验证.json 与 validation_logs/。最后 ZIP 解压验收的收据放 ZIP 外侧，避免自引用。

模型方法和性能结论没有因便携封装改变。原数据日期已公开，仍为历史回测，非新独立留出。
